# 0.8 实施与验收

2026-09-30。状态：**M1 界面及 M2 操作首批已实现，0.8 完整范围尚未交付**。本分支基于 `codex/plan-0.8` / `1cc2016`，范围见 [计划](plan-0.8.md)。0.7 的未验收项继续保留，见 [0.7 验收](validation-0.7.md)。

## 已实现：测试环境隔离

- QA 构建增加 `PageglassRequiresIsolatedProfile` 标记，在创建应用和访问浏览器存储之前检查 `--qa-profile`。无参数重开时以退出码 2 拒绝运行；正常构建不受影响。
- QA 参数先校验再建目录：绝对临时路径、窗口宽度与外观、重复和缺失参数、身份文件符号链接均检查。已有隔离配置保留网站存储标识。
- 自动 smoke 使用独立命名剪贴板，真实浏览器与手动 QA 仍使用系统剪贴板。复制失败、捕获取消和删除旧包的断言保留；单元测试也不再写入用户剪贴板。
- `scripts/build-qa.sh` 生成标记过的隔离 QA 包；不会安装或替换正常应用。

M0 验证：18 个单元测试通过，1 个需要隔离旧配置输入的迁移测试跳过；arm64 release / QA 构建通过。真实 WebKit smoke 的 134 项检查通过，运行前后系统剪贴板 changeCount 均为 480。直接无参数运行 QA 包退出码为 2，运行前后正常 `browser.json` 的 SHA-256 相同。该阶段构建为 `0.8.0-alpha.1` / 10；当前 M1 构建为 build 11。

## 已实现：快速操作与捕获连续性首批

M2 构建为 **0.8.0-alpha.1 / 12**，仍是开发预览，未安装到正常应用目录。

- `⌘K` 按已开标签、书签、历史和操作分组搜索；↑↓ / Enter / Esc 可用，复用原有导航和菜单动作，组合输入期间不执行命令。没有匹配时不自动转成联网搜索。
- 捕获结果改为 380 pt 的浏览器内右侧覆盖面板，保持网页视口、复用同一份详情视图；新选取、切换标签及导航时收起。Esc 关闭后返回网页，关闭面板不删除捕获。
- 主操作为复制给 Codex，截图复制、参考和 Finder 收入更多菜单；共享捕获历史详情。大图可按适合窗口 / 50% / 100% / 200% 查看，支持滚动和 `⌘W` 关闭；关闭时释放大图引用。
- 选取和捕获状态条也改为原生覆盖层，不在截图过程中挤压网页；增加「上一级」入口。清理通知会重新检查结果并禁用失效操作，复制仍再次校验文件。

验证：最终 WebKit smoke **183 项通过**（增加 22 项工作流检查），18 个单元测试通过、1 个迁移测试跳过，arm64 release / QA 构建通过。覆盖实际 WKWebView 的十次连续捕获、十个独立包、同一个侧面板、窗口数不增加、视口不变、下一次选取恢复、清理后的操作失效，以及原生快速操作匹配 / 焦点 / 输入法保护。构建与检查摘要见 [工作流报告](validation-data/0.8-workflows.json)。

## WebExtension 技术样机

独立脚本 `scripts/extension-probe/run.sh`，不进入应用运行时。实际运行于 macOS 27.0 (26A428)，使用公开 API、独立 UUID 的扩展和网站数据存储，以及自有回环页面；退出时清理本轮测试数据。报告保留实际失败，脚本失败退出不会伪装为通过。

本轮三个自有 MV3 样本的实测结果：**24 个检查通过，2 个请求规则权限检查失败**。原始结果见 [样机报告](validation-data/0.8-extension-probe.json)，保留失败退出码和源码 / 二进制哈希。

| 能力 | 观察结果 |
|---|---|
| action 弹窗 | 实际 WebKit 弹窗加载并显示 |
| storage / runtime | 弹窗读写存储、向 MV3 后台 worker 发送消息并收到回复 |
| 停用后重新启用 | 使用显式稳定的 `uniqueIdentifier` 与持久配置后，存储计数保持；非持久配置不能作为普通插件的设置存储 |
| 站点内容脚本 | 仅声明网址时不注入；明确授权后注入；撤权或停用后重新加载不再注入；重新启用后恢复 |
| 捕获桥隔离 | 捕获隔离世界的消息桥实际存在，页面扩展内容脚本与插件弹窗读不到它 |
| 主世界执行 API | 样机通过公开 `unsupportedAPIs` 关闭程序化脚本执行与动态脚本注册；静态 manifest 的 MAIN world 仍需在安装时拒绝 |
| 声明式请求规则 | 指定请求被拦截，不匹配请求正常；撤销站点权限后系统报告拒绝，但请求仍被拦截；卸载上下文解除拦截，带拒绝权限重载后仍会拦截 |
| 私密范围 | 上下文未授予私密数据或 file URL 权限；无痕窗口不接入控制器的产品级验证尚未完成 |

**准入决定：DNR 暂不进入可安装扩展的支持列表。** 这两项失败会保留在样机报告中，不能把用户撤权后的继续拦截描述为支持按站点管理。需要进一步确认 WebKit 行为或新的可验证方案；不降低撤权要求，也不以私有 API 绕过。弹窗、静态内容脚本及存储继续作为首批宿主实现目标。

样机不是扩展产品验收：安装包边界验证、原生权限弹窗、站点授权持久化、完整标签事件、多窗口/无痕、至少两个真实开源插件全流程、macOS 14 / 15.4 实机仍待完成。源码读取和公开 API 文档不能替代这些检查。

## 已实现：扩展宿主首批，验收未完成

当前构建 **0.8.0-alpha.1 / 13**。本地目录 / ZIP 的独立副本导入、安装前权限说明、更新、停用、移除及保留数据选项已经接入；工具栏与设置提供管理入口。扩展 action / 选项使用真正的 WebKit 页面，网站授权可允许、拒绝及撤销。无痕窗口不装载扩展控制器，受保护页面作为活动页时向扩展隐藏该窗口，不伪造当前标签。具体范围见 [扩展开发预览](extensions-0.8.md)。

最终真实 WebKit smoke **207 项通过**，其中扩展宿主 **24 项**；单元测试 **27 项通过、1 项迁移测试跳过**，arm64 release / QA 构建通过。摘要、检查清单与两种应用二进制哈希见 [宿主报告](validation-data/0.8-extension-host.json)。扩展测试使用持久 UUID 测试存储及自有回环网页，结束清除本轮测试数据。

- 实际运行链路：弹窗与 storage.local、MV3 worker 通信、选项页隔离；tabs 查询 / 按指定位置后台新建 / 关闭，标签创建、关闭、激活、移动和属性事件。
- 权限：安装不自动授权；允许后注入，撤权或停用后刷新不注入；无痕无控制器，普通页面恢复后可查询，内部页及无痕标签不泄露；内容脚本、弹窗和选项页不能取得原生捕获桥。
- 生命周期：停用重启保留存储；拒绝无效更新；模拟登记写入失败，候选卸载并重载旧版本；更新保留身份和站点授权；重建宿主从磁盘恢复；移除程序保留数据、重新安装继续读取、显式清除数据。这里的宿主重建发生在同一进程，不能替代真正退出应用再打开。
- 包验证：目录副本不随来源变化；拒绝符号链接、目录穿越、ZIP 冲突路径 / CRC 错误 / 超限解压、无效版本与不支持的权限。系统临时目录路径归一问题已修正；stored / deflate 与压缩空目录均通过。

完整回归曾发现旧文档图标尚未清除时测试过早结束等待；现在同时等待新站点缓存，保留原有两个断言。宿主恢复测试曾遇到弹窗未就绪，已增加错误内容诊断，并释放旧资料持有的控制器后再重建，随后完整 207 项通过；真实重启仍为单独验收项。

**实际 UI 仅部分观察：** CUA 看到了 900 pt 工具栏扩展入口、空管理页控件、目录选择和含权限 / 网站范围的安装确认；点击安装后，隔离登记文件已有启用的自有样本。此后 AX 和截图连续返回 `-10005 timeoutReached`，重新绑定及重置工具会话也未恢复。QA 主线程采样主要在事件循环等待，未见忙循环，但无法据此确认安装后的界面状态或排除 UI 问题。权限弹窗、弹出页、停用 / 更新 / 卸载、真正退出重开、明暗管理界面与多窗口的手动验收保留待办；未替换已安装应用。

至少两个真实开源插件仍未完成全流程。DNR 的旧样机失败继续保留，安装器拒绝相应能力；不能把自有样本通过称为通用 Chrome 插件兼容。
