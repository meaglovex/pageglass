## WebExtension 技术样机

独立脚本 `scripts/extension-probe/run.sh`，不进入应用运行时。实际运行于 macOS 27.0 (26A428)，使用公开 API、独立 UUID 的扩展和网站数据存储，以及自有回环页面；退出时清理本轮测试数据。报告保留实际失败，脚本失败退出不会伪装为通过。

本轮三个自有 MV3 样本的实测结果：**24 个检查通过，2 个请求规则权限检查失败**。原始结果见 [样机报告](validation-data/0.8-extension-probe.json)，保留失败退出码和源码 / 二进制哈希。

| 能力 | 观察结果 |
|---|---|
| action 弹窗 | 实际 WebKit 弹窗加载并显示 |
| storage / runtime | 弹窗读写存储、向 MV3 后台 worker 发送消息并收到回复 |
| 停用后重新启用 | 使用显式稳定的 `uniqueIdentifier` 与持久配置后，存储计数保持；非持久配置不能作为普通插件的设置存储 |
| 站点内容脚本 | 仅声明网址时不注入；明确授权后注入；撤权或停用后重新加载不再注入；重新启用后恢复 |
| 捕获桥隔离 | 捕获隔离世界的消息桥实际存在，页面扩展内容脚本与插件弹窗读不到它 |
| 主世界执行 API | 样机通过公开 `unsupportedAPIs` 关闭程序化脚本执行与动态脚本注册；静态 manifest 的 MAIN world 仍需在安装时拒绝 |
| 声明式请求规则 | 指定请求被拦截，不匹配请求正常；撤销站点权限后系统报告拒绝，但请求仍被拦截；卸载上下文解除拦截，带拒绝权限重载后仍会拦截 |
| 私密范围 | 上下文未授予私密数据或 file URL 权限；无痕窗口不接入控制器的产品级验证尚未完成 |

**准入决定：DNR 暂不进入可安装扩展的支持列表。** 这两项失败会保留在样机报告中，不能把用户撤权后的继续拦截描述为支持按站点管理。需要进一步确认 WebKit 行为或新的可验证方案；不降低撤权要求，也不以私有 API 绕过。弹窗、静态内容脚本及存储继续作为首批宿主实现目标。

样机不是扩展产品验收：安装包边界验证、原生权限弹窗、站点授权持久化、完整标签事件、多窗口/无痕、至少两个真实开源插件全流程、macOS 14 / 15.4 实机仍待完成。源码读取和公开 API 文档不能替代这些检查。

## 已修复：Esc 崩溃与真实扩展操作反馈

当前构建 **0.8.0-alpha.1 / 17**。普通网页按 Esc 曾实际触发 `NSInvalidArgumentException`：`BrowserWindow.cancelOperation` 向没有实现该选择器的父类发送消息。现在普通空闲网页保持当前内容与焦点；加载中的网页停止剩余加载，保留已加载文档。捕获、提示和侧面板的取消行为保持原路径。

安装新扩展后自动选中新条目，成功反馈写明名称；避免在旧条目上继续设置权限。只有内容脚本、未声明 action 的扩展不再暴露 WebKit 合成的空动作，集合菜单改为打开该扩展的「网站权限…」；已加载时管理页明确无工具栏动作，禁用对应常驻入口。

**最终 243 项 smoke 通过，37 项单元测试通过、1 项真实数据副本迁移测试跳过；ARM64 release / QA 构建通过。** 相比 build 15 增加 6 项：普通网页及加载中 Esc、安装选中、无合成 action、对应权限入口及授权后的静态脚本。摘要与源码 / 二进制哈希见 [本轮报告](validation-data/0.8-escape-extension-ux.json)。新增自有测试扩展最初缺少 WebKit 要求的 description，导致一次回归失败；补齐测试包元数据后保留全部原断言通过，没有放宽宿主准入。

**真实 UI：** build 16 的普通 YouTube 网页重复 Esc 保持窗口与焦点；最终 build 17 原生文件对话框安装自有内容型扩展后，新行自动选中、名称反馈正确、无效动作禁用。两个未修改的开源插件分别记录版本与许可：Shorts Blocker 首页导航隐藏的安装、拒绝、允许、撤权、更新、停用、真正退出重开、重新启用和保留数据卸载均有实际界面结果；GHUX 弹窗设置、更新和真正重启保留通过，但启用后 GitHub 差异布局破坏，不能算兼容通过。详细边界见 [逐功能兼容记录](extension-compatibility-0.8.md)。

以上使用未登录的独立临时配置；没有使用 token、审核或删除仓库，没有替换正常用户应用。至少两个真实插件全流程通过仍未满足。停用的内容型扩展仍可勾选工具栏偏好但不会产生按钮，这一管理状态留待收紧。
