# 0.10 性能优化计划

基线：0.9.0-alpha.1 build 33，提交 c9834ac。目标是减少真实的重复工作和内存中转，同时保留页面状态、捕获质量、历史记录及隔离边界。

## 审查发现与本期范围

1. 地址栏建议：结果最多 8 条，当前实现仍扫描并分配整个匹配数组。改为按既有书签优先、历史随后和 URL 去重规则收集，到 8 条即停止。
2. 标签外观：每次切换都会重设所有标签的文字、图标、提示和无障碍值。只提交变化的字段，保留选中状态、动态标题、网站图标和键盘焦点反馈。
3. 扩展状态同步：每个新标签快照在线性数组中查找旧快照，多标签时形成平方级查找。改为按对象身份建立一次索引，保持事件顺序与可见范围。
4. 截图编码：NSImage → TIFF → NSBitmapImageRep → PNG 的中间解码带来额外大图副本。直接使用位图/CGImage 编码 PNG，并把压缩移出主线程；取消后不得提交文件。

不通过关闭安全检查、降低截图像素、丢弃历史、自动销毁用户后台标签或虚构硬件开关获得结果。

## 验证

- 定向正确性：建议顺序/去重/空查询；图标、标题与选中状态；PNG 像素、透明度、Retina 尺寸和取消；扩展事件。
- 原负载对照：同机同系统、同一测量探针与页面，各三轮；记录启动、标签切换、滚动、空闲 CPU、捕获耗时及整组物理内存。前台、温控或采样失效的轮次不计成绩。
- 热点对照：用相同固定数据独立测建议查询、标签更新和图片编码，公开输入、输出等价校验及单位。局部耗时不能冒充整个浏览器提速比例。
- 单元测试、完整 smoke、实际安装版检查；保留 0.8 / 0.9 尚未完成的跨系统和长期验证。

## 当前状态

四项性能改动与本地书签建议导航修复已完成，最终 build 35 已安装。50 项常规单元测试及 338 项完整 smoke 通过；定向微基准三轮、原生对照每版六轮完成。性能范围及标签切换尾部波动调查见 [性能报告](performance-0.10.md)，最终包证据见 [验收记录](validation-0.10.md)。

没有宣称整体网页更快或长期更省电。真实多站点、视频、长期与跨系统验收继续保留。
