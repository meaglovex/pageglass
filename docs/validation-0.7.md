# 0.7 开发版验收进度

2026-09-29，0.7.0-beta.1。**尚未完成 0.7 发布验收。** 本文是当前进度，不能用来推定未列出的功能已经通过。

## 已实现

- 标签控件复用，标题/图标只更新对应标签；活动标签自动滚入视野，固定位置的新建入口和可搜索标签列表。
- 地址建议区分标题、网址、书签/历史；组合输入期间不截获确认键；书签按可用宽度排列并提供溢出入口。
- 按标签保存加载失败状态，提供持续可见的重试、编辑地址操作；窄窗口收起次要工具，设置使用齿轮图标。
- 选取时显示父级路径和尺寸；交互记录显示步数；捕获阶段与取消入口持续可见。
- 捕获先写临时目录，全部完成后提交为历史包；取消和失败清理本次临时文件，晚到的截图结果不写入剪贴板。
- 结构化完整/部分捕获状态，截图预览、缺失说明、重新复制与只读参考预览；损坏的截图拒绝再次复制并保留原剪贴板。
- 捕获历史搜索、缩略图、来源/时间/大小/到期状态、选择清理；后台扫描与按需缩略图，兼容旧包。
- 捕获清理设置显示占用空间，缩短保留期限时确认已有包的清理范围；最新结果不常驻完整长截图位图。

## 当前检查证据

- `swift test --build-system native`：15 项常规测试通过，另有 1 项选择本地隔离副本后运行的升级测试通过；覆盖旧记录、损坏记录隔离、符号链接排除、逐项删除范围和失败保留。CI 默认跳过需要用户副本的该项。
- `scripts/build.sh`：arm64 release 应用构建及本地临时签名通过，版本标记为 beta。
- `scripts/smoke.sh`：`qa-output/20260929-181827/report.json` 中 116 项通过。新增覆盖 1 / 10 / 30 标签在 900/1280/1440 pt 下的可见性、控件身份保留、标签搜索、20 书签溢出、组合输入保护、错误状态隔离与恢复。
- 捕获新增回归覆盖截图/资源/落盘阶段取消、整页取消后滚动和临时样式恢复、剪贴板保持、写入失败、目录重新读取与复制。修改自有参考 HTML 加入测试脚本后，预览仍不执行；关闭预览释放 WebView。
- 新增检查实际资源响应传输中的取消、隔离 abort hook 释放、缺失资源和元素裁切的结构化部分结果；取消后不提交包、不改剪贴板。
- 历史组件在实际 AppKit 窗口加载 200 份含 PNG 的合成旧包，搜索、重新复制、目录监测、真实废纸篓删除及还原、重新打开列表均通过。该轮后台扫描约 0.24 秒，属于单次组件检查，不能代替人工滚动流畅度验收。
- 对真实已有数据制作隔离副本后验证保存和重读；书签、设置、历史、标签内容和旧捕获保留，原文件哈希未变。唯一移除的是此前已取消的 `pinned` 字段，未丢失页面。副本及哈希留在忽略的 `qa-output/upgrade-copy-*`；复跑命令为 `python3 scripts/verify-upgrade.py`，只修改隔离副本。
- 从本轮干净捕获包生成增加「查看详情」按钮的离线原型；新弹窗开关及已观察的展开/收起通过。基准截图平均 RGB 差约 0.69%，已观察的收起状态相同。证据位于 `qa-output/prototype-20260929-181128-73184/`；这是文件读取链路，不代表完成了 Codex 输入框粘贴。
- 实际 QA 应用中打开捕获结果并查看截图，点击重新复制得到成功回执；从结果进入捕获历史、选择记录并打开参考页面。测试使用 `qa-output/ui-07-capture/`，没有操作用户真实捕获包。
- 界面检查发现长文件路径占位与列表文字截断问题，已调整代码；这些最新视觉调整仍需再次查看实际窗口。

测试报告、截图、捕获包和运行配置保留在忽略的 `qa-output/`，不进入公开仓库。先前版本的验收记录见 [validation.md](validation.md)，其中按版本排列的旧限制不代表当前实现状态。
