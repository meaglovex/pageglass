# 0.7 开发版验收进度

2026-09-29，0.7.0-beta.1。**尚未完成 0.7 发布验收。** 本文是当前进度，不能用来推定未列出的功能已经通过。

## 已实现

- 标签控件复用，标题/图标只更新对应标签；活动标签自动滚入视野，固定位置的新建入口和可搜索标签列表。
- 地址建议区分标题、网址、书签/历史；组合输入期间不截获确认键；书签按可用宽度排列并提供溢出入口。
- 按标签保存加载失败状态，提供持续可见的重试、编辑地址操作；窄窗口收起次要工具，设置使用齿轮图标。
- 选取时显示父级路径和尺寸；交互记录显示步数；捕获阶段与取消入口持续可见。
- 捕获先写临时目录，全部完成后提交为历史包；取消和失败清理本次临时文件，晚到的截图结果不写入剪贴板。
- 结构化完整/部分捕获状态，截图预览、缺失说明、重新复制与只读参考预览；损坏的截图拒绝再次复制并保留原剪贴板。
- 捕获历史搜索、缩略图、来源/时间/大小/到期状态、选择清理；后台扫描与按需缩略图，兼容旧包。
- 捕获清理设置显示占用空间，缩短保留期限时确认已有包的清理范围；最新结果不常驻完整长截图位图。

## 隔离的实机验证入口

`--qa-profile /tmp/<独立目录>` 为手工 UI 验证启用独立书签/会话/历史、网站数据标识和 Captures；使用正常启动、保存和恢复路径。仅接受临时目录的子目录，解析符号链接后拒绝其他路径。可搭配 `--qa-width 900|1280|1440` 和 `--qa-appearance Aqua|DarkAqua`，只影响测试窗口，不修改系统外观。测试前准备合成 `browser.json`；不复制真实 Cookie。正常启动未传参数时保持原存储行为。

```sh
dist/Pageglass.app/Contents/MacOS/Pageglass --qa-profile /tmp/pageglass-manual-qa --qa-width 900 --qa-appearance Aqua
```

测试启动必须先确认进程仍在运行，再连接 UI 工具，防止工具在启动失败后自行打开不带测试参数的实例。
