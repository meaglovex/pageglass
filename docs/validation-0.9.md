# 0.9 硬件加速检测验收

2026-10-09，版本 **0.9.0-alpha.1 build 32**。本期增加设置中的图形状态与本地检测；硬件加速仍由系统 WebKit 自动管理，未新增总开关或改用私有 GPU API。

## 结果

- 单元测试 47 项执行：46 通过、1 项真实升级配置测试按默认条件跳过、0 失败。新增测试覆盖缺失像素、错误像素、整数异常、无计算读回、失败/不支持/未知状态和报告往返。
- 最终 release 完整 smoke **334 项通过**，包括 13 项新增图形检查；原生设置最小尺寸在浅色/深色下均检查结果和操作不越界。此前独立图形专项也通过 13 项。
- 本机 M5 / macOS 27.0.1 返回真实 Metal 设备 Apple M5。WebGL 1 / 2 着色器绘制读回 RGBA `[32,128,223,255]`，渲染器 Apple GPU。WebGPU 实际计算读回 42。
- VideoToolbox 返回 H.264、HEVC、AV1 硬解码支持。本次未播放视频测实际硬解码路径，页面和报告明确该边界。
- 完成检测后临时 WKWebView 释放；关闭设置时可取消未完成请求，迟到回调不生成陈旧结果。复制按钮输出实际 JSON，自动测试使用隔离剪贴板。
- 实际打开独立测试版及安装版的“设置 → 性能与图形”，检查未检测状态、检测后结果、暗色显示。独立测试版复制动作显示成功反馈，之后已正常退出。
- 安装至 `/Applications/Pageglass.app`，严格深度签名校验通过，与 release 可执行文件逐字节一致。旧 0.8 安装包保存在本机缓存备份目录。安装版已重新运行检测并留在结果页面。

## 保留的边界

这不是“0.9 首次开启 GPU”。0.8 已有 Apple GPU 的 WebGL 记录。此功能只验证本地测试文档，不保证任意网站、每一帧或每段视频都使用硬件，也不承诺降低内存、功耗或提高速度。

本机仅验证 M5 / macOS 27.0.1；其他支持的 macOS 版本和设备没有实机覆盖。0.8 的其他发布验收项继续参照 [0.8 验收记录](validation-0.8.md)，不会因为本次 334 项 smoke 通过而自动关闭。当前仍为开发预览，未创建正式发布。
