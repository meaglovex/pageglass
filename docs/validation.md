# 0.4 验证记录

> 本文件保留按时间排列的历史验收。当前 0.7 开发版结论与未完成项见 [validation-0.7.md](validation-0.7.md)；不要将早期的“未实现/未发布”条目当作当前状态。

测试环境：2026-09-29，本机 macOS arm64，Apple Swift 6.4 / Xcode SDK 27，最低部署目标 macOS 14。构建脚本使用 SwiftPM native backend，避免 Swift 6.4 默认 Xcode backend 的产物路径差异；此参数在新工具链已标记 deprecated，后续应迁移。

## 已验证

- arm64 release 应用构建、临时签名；App 内资源已修正为从 `Contents/Resources` 加载，UI 中观察到实际加载 URL。
- `swift test --build-system native` 6 项测试：地址路由、搜索引擎、书签/历史/设置/会话磁盘恢复、损坏文件保护、下载状态持久化与中断恢复。
- 实际 WKWebView 自动检查通过 55 项：按钮点击展开、元素子树与截图、整页 DOM 与长截图、滚动位置恢复、密码/隐藏/文本输入值不进代码、事件属性清理、HTML CSP、展开状态记录、剪贴板包路径、WebGL 可用；重新打开导出 HTML 后，卡片宽高与原页面误差小于 1 CSS 像素。
- 新增引擎检查：独立标签 WebView、切回不重载、关闭标签恢复、排序与固定、书签建议、缩放、页内查找、无痕 localStorage 双向隔离、会话懒加载、关闭最后标签释放渲染器。
- WebGL 实际返回 `renderer: Apple GPU`、`vendor: Apple Inc.`。这证明此机 WebGL 使用 Apple GPU；不代表每种视频格式和每个图层都硬件加速。
- 人工看过输出的局部截图、长截图：文字和布局正确，长截图包含页面底部标记，没有末屏重复。
- 实际 UI 中用 ⌘T / ⌘L 新建标签并加载 https://example.com，观察到 HTTPS 就绪和页面内容；修正并验证新标签地址清空、切回标签后的网址和标题同步。
- 通过实际 App UI 打开练习页，启动「捕获元素」，选取「新建需求」按钮：临时回执成功，导出 1 个节点，原按钮保持折叠，未执行原网页动作。
- 0.2 实际 UI：顶部标签栏 + 地址栏两行共 80 pt，1280×860 窗口正文高度 780 pt（关闭书签栏）；已查看原生截图，取消常驻底栏。
- 0.2 实际 UI：从本地 HTTP 测试页添加书签、打开管理窗口、查看历史、输入地址建议并用 ↓ / Return 跳转；设置保存书签栏后，在浏览窗口观察到书签按钮。
- 0.2 实际 UI：退出并重开应用，恢复测试页 URL 和内容。下载链接 → 原生保存面板 → 下载管理中“已完成”；保存文件与测试服务的 4096 字节内容逐字节一致。
- 实际应用主进程一次空闲采样约 98 MiB RSS（不含 WebKit 子进程），仅记录调试样本，不能用来声称比 Chrome 省内存。

- 0.3 HTTP 资源页：PNG、带查询串的背景图、空内容伪元素背景、SVG 图片及所用 TTF 均保存；SVG 图片转 PNG，未保留脚本。选区外的 SVG symbol / gradient 被保留。
- 0.3 使用全新非持久 WebView 并通过内容规则禁用所有 HTTP(S) 请求，重新打开本地捕获；图片与字体加载、SVG use 几何、checked/open 状态均通过。已查看原图和离线图。
- 0.3 视觉对照：`qa-output/20260929-023219/offline-visual-comparison.json`，原图与离线选区均为 920×580，178674 个抽样 RGB 通道平均绝对误差 0。此结果仅覆盖自建固定测试页，不代表任意网站。
- 0.3 失败边界：跨域拒绝、超大资源、伪装为 image/png 的 HTML 均不写入资产文件并明确记录；未关闭 CORS 或 TLS 校验。

- 0.4 交互记录：实际隔离世界脚本桥记录初始画面、details 展开前后状态和 DOM 变化；时间线、逐步 PNG / HTML / JSON 随最终捕获一起导出。最新完整报告为 `qa-output/20260929-030951/report.json`，55 项通过；6 项单元测试通过。
- 0.4 隐私与生命周期：普通浏览记录器关闭；密码事件不记录，文本输入和空属性 contenteditable 内容不进入 HTML、操作日志和元数据。停止后不再接收操作；8 次操作后自动停止；快连续操作明确标记缺失画面。切换标签停止，导航清空，导航失败保留旧页面时也确实停止脚本监听。
- 0.4 元素选取：进入选择模式前保存仍在等待的最后一次操作，验证实际画面已写入，避免选择高亮混入交互截图。
- 0.4 离线交互预览：从捕获根目录的 `interaction-history.html` 进入，禁用全部 HTTP(S) 后分别打开初始与展开状态，图片有效且 details 各自状态正确。已查看保存的步骤截图；截图会包含可见输入内容，与“仅日志和代码排除输入值”的边界一致。

- 捕获包到原型：完整工作台样例新增“查看详情”按钮及弹窗，复现已观察到的展开/收起；禁网运行和截图对照通过，详见 [prototype-validation.md](prototype-validation.md)。最新浏览器回归 `qa-output/20260929-031825/report.json` 55 项通过。

自动化报告、截图和本地测试产物位于忽略的 `qa-output/` 下，通过 `scripts/smoke.sh` 可重跑；使用干净的测试网站数据，不读取用户账号。脚本自动启动并关闭回环测试服务；字体夹具从系统读取，不把字体复制进仓库。

## 未通过验收 / 未验证

- Codex 输入框的实际粘贴验收：工具返回 `Computer Use is not allowed to use the app 'com.openai.codex' for safety reasons.`，因此没有操作或绕过。已经检查本机粘贴处理代码和系统剪贴板，最终输入框行为仍需用户粘贴验证。
- 0.4 新增记录按钮的真实鼠标操作仍未验收；再次检查原生界面，工具仍返回 `The Mac is locked and automatic unlock could not unlock it.`。自动检查不替代这项 UI 验收。
- 原生鼠标坐标操作被电脑工具返回 `noWindowsAvailable`；已通过真实可访问性点击走完选择链路，但连续鼠标 hover 高亮、↑/↓ 调整选区需人工试用。
- 已准备固定 Speedometer 3.1、三轮交替运行和 1/5/10 个完整加载标签的对照工具，验证了 WebKit XPC 进程归属及系统 footprint 读取。锁屏前置检查已实际阻止测量，正式 Chrome 对照没有开始，详见 [performance.md](performance.md)。
- 未进行与 Chrome 同负载的性能/总内存对照。**Chrome 级速度、更少资源消耗尚未达标验收。**
- 上传流程已打开原生文件选择器，后续操作时电脑工具返回 `The Mac is locked and automatic unlock could not unlock it.`，未上传测试文件。未绕过锁屏。
- 下载进度已实现，实际 UI 只验收小文件完成链路；慢速下载取消、跨窗口取消、WebArchive 保存/打印、鼠标拖动标签未做完整 UI 验收。媒体权限、复杂登录、Passkey、DRM、跨域 iframe、超长虚拟列表仍未做站点矩阵验收。
- 已实现受预算约束的图片/字体打包；未对真实大型网站和跨域受限资源做完整离线验收，不承诺任意网站离线 1:1。
- 已完成自建工作台样例的原型重建与画面比较；未进行真实任意网站的质量评分。当前导出仍是参考素材，不是原业务项目源码。
- 应用包不包含系统 WebKit；体积仅说明分发成本，不能替代总进程资源测试。
- 未配置远程仓库、未推送、未发布/公证。
