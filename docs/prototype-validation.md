# 捕获包到可编辑原型

此验证只覆盖自建工作台样例，证明捕获素材可用于继续开发；不替代 Codex 输入框粘贴验收，也不代表任意网页或未知业务逻辑可自动复刻。

## 验证方式

运行 `scripts/smoke.sh` 后，报告中的 `cleanPage` 指向未注入安全测试字段的工作台整页捕获，包含展开前后的交互历史。原型生成器只读取此捕获包的 `capture.json`、`reference.html`、资源与交互历史，不读取原网页源文件。

```sh
scripts/prototype-qa/run.sh /absolute/path/to/capture-directory
```

它保留捕获的 DOM / CSS，在“本月活跃用户”卡片右上角增加“查看详情”按钮及可关闭的原生 HTML dialog，并依据记录的状态重建展开/收起。只有新写的脚本获得 CSP nonce，原页面脚本仍不导入。原型不连接业务后台，弹窗内明确标注本地模拟。

独立 Swift 验证器使用非持久 WKWebView、禁止全部 HTTP(S) 请求，打开生成的本地 HTML 并实际调用按钮，输出截图与 `verification.json`。脚本和验证器只用于开发，不随浏览器发布。

## 当前结果

2026-09-29，捕获包 `qa-output/20260929-031825/1790623106-1A915B16`；原型与报告 `qa-output/prototype-20260929-0320/`。

- 整页基准：暂时隐藏新增按钮，对比原长截图。1280×1203 图像，385280 个抽样像素，平均绝对 RGB 误差 0.006628（约 0.66%），通道平均误差超过 10% 的像素比例约 0.31%。原截图逐屏拼接，复现图整页渲染，二者都有缩放处理；这不是逐像素完全一致的结论。
- 交互状态：使用记录时的视口，执行收起操作并对比原始操作前截图。1800×1096 图像，493200 个抽样像素，平均误差和显著差异比例均为 0。
- 新增详情按钮能打开 dialog，关闭按钮可关闭；已有展开和收起行为、ARIA 状态通过检查。
- 已查看新增按钮和弹窗的实际渲染图。实现过程修正了弹窗文字受捕获样式继承影响的问题；按钮文字和说明的颜色现在正确。

原型为固定捕获视口的可编辑 HTML，保留了计算样式而非原项目组件结构。尚未验证响应式重构、大型真实网站、复杂登录、跨域受限素材、未访问分支或服务端业务。实际 Codex 粘贴入口仍受电脑工具限制，没有通过本验证绕过或冒充完成。
