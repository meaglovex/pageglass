# 捕获整理与交付（0.8 开发预览）

在捕获结果或历史详情中选择「标注与备注」。原截图、原参考 HTML、`capture.json` 和原 `PROMPT.txt` 不会被编辑器改写。

## 整理和标注

- 修改显示名称、填写备注与修改要求；名称最多 200 字，备注最多 8000 字。历史可按名称、原网页标题、网址和备注搜索，再按元素 / 整页以及今天 / 最近 7 天 / 最近 30 天筛选。
- 矩形和箭头通过拖动添加；序号和文字点击添加。切换到「选择」后拖动已有标注，方向键微调，Shift + 方向键移动 10 个图片像素，Delete 删除。文字或序号在右侧修改并按 Enter 应用。
- 支持撤销 / 重做、适合窗口及 50% / 100% / 200% 缩放。最多 200 个标注，单条文字最多 500 字。当前不能拖动控制点调整标注尺寸；可删除后重画。长文字靠近边缘可能超出截图，应检查导出的图片。
- `⌘S` 或「保存」写入独立的 `pageglass.json`。关闭有未保存修改的窗口、退出应用时会询问；关闭浏览窗口不会销毁仍打开的编辑器。再次编辑同一个包会回到原编辑窗口。
- 两个独立编辑会话使用修订标识检查冲突；损坏、未来版本或符号链接的编辑文件不会被覆盖。原捕获仍可查看，错误会单独显示。
- 「导出标注图片」保存一张 PNG，保留原图像素尺寸；这不代替保存可编辑数据。不能导出进原捕获包覆盖证据。

已保存的备注及标注数据路径会加入「复制给 Codex」的本机引用。复制仍是文本引用；只有实际接收工具读到文件，才算交付成功。

## 可携带包

在详情「更多操作」中选择导出 ZIP 或文件夹，再选择新的保存名称。已有目标不会被覆盖。编辑窗口有未保存修改时，需先保存。

包内包含：

| 文件 | 内容 |
|---|---|
| `screenshot.png`、`reference.html`、`capture.json` | 截图与参考结构；导出副本中的本机文件来源被移除，网页 HTML 增加禁止脚本的 CSP |
| `assets/`、`interaction-history/`、`interaction-history.html` | 已存在且格式、路径符合捕获规则的离线资源和观察记录 |
| `pageglass.json` | 已保存的名称、备注和可编辑标注 |
| `annotated.png` | 存在标注时生成的标注图片 |
| `PROMPT.txt` | 重新生成的相对路径读取说明 |
| `portable.json` | 相对文件清单、字节数、SHA-256 与路径调整说明 |

只导出已知捕获文件，不复制浏览器配置、Cookie、扩展数据或目录中的任意附加文件。逐级拒绝资源符号链接；最多遍历 1000 项、单张 PNG 128 MiB、其他单文件 32 MiB、写入内容合计 256 MiB。失败移除本轮暂存目录，保留原捕获。ZIP 使用系统 `ditto` 处理验证后的独立副本，不运行网页脚本。

包不依赖原捕获目录。自动生成的交付引用改为相对路径，本机 `file:` 地址不可携带，替换为不可用地址并记入说明；不会为此读取本机目标文件。缺失的网络资源仍可能需要联网，不会在导出时重新抓取。截图和网页正文仍可能包含原本可见的路径或个人信息，导出不是自动脱敏。

整个包需由使用者自行附加给接收工具。本机目录搬移、系统 ZIP 解包及 WebKit 禁用脚本预览已做自动检查；实际目标工具的附加 / 读取 / 原型重建，完整键盘 / 中文输入 / VoiceOver、明暗与最小尺寸仍须分别验收。当前状态与证据见 [0.8 验收记录](validation-0.8.md)。
