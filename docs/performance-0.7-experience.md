# 0.7 原生体验测量

2026-09-29，**测量已完成，性能发布验收仍未完成**。本报告不代表 Chrome 对照，也不把页面 rAF 间隔当作屏幕呈现延迟。

## 条件与原始记录

同一台 Mac17,4，10 核、16 GiB、macOS 27.0（26A428），显示器报告最高 50 Hz。两版均为 arm64 release，使用同一探针与自有长页面；每轮独立空配置、10 个全部加载标签，保持前台、未锁屏、非省电、温控 nominal。0.6 基于 `b21b6fd`，0.7 build 9 基于 `633745b`；探针只加入临时源码副本，不进入分发应用。

[公开原始样本](benchmarks/0.7-experience.json)包含三个轮次的完整切换与滚动时间序列、按进程名汇总的 CPU 增量、物理内存、版本及源码/探针/运行器/二进制哈希。未附浏览器配置、捕获内容或用户数据。本轮先测 0.7，再立即复跑 0.6；两组完整记录分别为 `qa-output/experience-07/pageglass-experience-results-n3axwoka/`、`qa-output/experience-07/pageglass-experience-results-r1e0l0x5/`。复跑方法和各指标口径见 [performance.md](performance.md#原生体验测量探针)。

## 三轮结果

表中为各轮结果的中位数；标签 P95 先在每轮 30 次切换中计算，再取三轮中位数。

| 指标 | 0.6 | 0.7 | 变化 |
|---|---:|---:|---:|
| 新进程启动至地址栏可输入 | 392.9 ms | 435.2 ms | +10.8% |
| 标签切换代理指标，中位数 | 40.03 ms | 40.00 ms | −0.08% |
| 标签切换代理指标，P95 | 80.09 ms | 41.03 ms | −48.8% |
| 四秒滚动的 rAF 调度间隔，P95 | 21 ms | 21 ms | 0% |
| 十个标签空闲，整组 CPU / 单核 | 1.05% | 1.28% | +0.23 个百分点 |
| 元素捕获服务至文件落盘 | 19.07 ms | 19.61 ms | +2.8% |
| 整页捕获服务至文件落盘 | 2232.01 ms | 2222.93 ms | −0.41% |

启动每次创建新进程，但未清除系统文件缓存；不是磁盘缓存冷启动。标签指标从原生激活调用到页面第二次 rAF 回调，包含 WebKit 往返和调度；不是物理点击到画面呈现的实测。捕获计时不包含人工选择及结果浮层展示。

## 回归调查

本轮启动和空闲 CPU 仍触发计划中的 10% 调查阈值，不能称为全面提速。

- 启动绝对差约 42 ms。0.6 单轮范围 388–399 ms，0.7 为 422–696 ms；保留了较慢的首轮。此前 build 8 的三轮中位数为 296→345 ms。新构建只修复失败导航的选取层清理，没有证据把启动波动归因于该修改；尚未定位稳定的启动瓶颈。
- 标签切换 P95 本轮为 80→41 ms，早先三个批次分别约为 80→140、80→73、80→120 ms。长尾主要出现在空闲后的第一次遍历，批次波动明显；不能将本轮改善宣称为已修复某个调度问题，也没有为跑分更改 WebKit 后台策略。
- CPU 使用公开的 Mach 时间计数并按设备时钟换算，已用独立 `getrusage` 校验。本轮差约 0.023 CPU 秒/十秒；0.6 主进程每十秒约 0.009–0.010 CPU 秒，0.7 约 0.009–0.015 秒，候选前两轮 GPU 增量较高。原因未证实，不能将浏览器壳或 WebKit 直接认定为根因。旧 `ps TIME` 的低精度样本不混入本报告。
- 元素捕获本轮增加约 0.54 ms，未持续超过 10% 阈值；build 8 的上一轮曾为 15.51→17.39 ms。若将 build 9 与更早的 0.6 批次比较，会得到 +26.5%，因此特意紧接着重测基线，同时保留该次比较 `qa-output/recovery-07/experience-against-earlier-baseline.json`。不删掉较慢轮次，也不据此保证所有页面均无回退。

build 8 的公开报告和原始样本保留在 [该次提交](https://github.com/meaglovex/pageglass/blob/e378f586022c2aadfcee0b30996552fe863927ee/docs/benchmarks/0.7-experience.json)。本页明确标记源码和批次，不把旧构建成绩当作 build 9 的成绩。

当前保持 beta。启动和空闲 CPU 的绝对差、波动及尚未定位的原因须纳入最终发布决定；不能由本报告自动豁免。Speedometer 对照见 [性能报告](performance.md)，完整内存与交互验收仍待完成，不宣传 Chrome 级速度。
