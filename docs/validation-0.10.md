## 审查修复（2026-10-15，build 36）

代码审查发现的问题在分支 `claude/review-fixes-0.10` 修复，每项单独提交：

- **捕获保真**：资源 token 改为带结尾分隔符并一次性整词替换，修复第 10 个起的资源被 `_1` 前缀替换成错误文件；void 元素（`<br>` 等）不再输出结束标签，修复 reference.html 中每个 `<br>` 变两个换行；选取拦截改挂在 window 捕获阶段；复制给 Codex 的页面标题限为一行、120 字并加引号。
- **数据**：浏览器数据写入失败只报告并在下次修改时重试，不再让本次运行的后续保存全部失效；读取失败仍禁止覆盖原文件。
- **浏览安全与可用性**：脚本弹窗需用户手势；JS 对话框、文件选择、下载位置和外部协议确认改为窗口表单，后台标签不弹出，可静音重复弹窗；新增 HTTP Basic / Digest / NTLM 登录；地址栏把局域网 IP、`.local` 与带端口的单词主机默认为 http，`v1.2` 一类版本号改为搜索，`about:blank` 可打开，`mailto:` 等交给外部应用确认。
- **资源**：下载进度只在整数百分比变化时更新；资料库关闭时不随存储变化刷新；扩展恢复最多等待 1.5 秒后就打开窗口；普通窗口的网站图标落盘缓存（最多 512 个），启动不再逐站请求书签图标。
- **构建**：`scripts/build.sh` 继续使用 native 构建系统。实测 SwiftPM 默认构建系统把二进制的 SDK 版本记为 14.0（native 为 27.0），AppKit 因此采用旧 SDK 行为，体验 smoke 中标签栏滚动条会截获标签点击；在原生构建系统移除前需另行解决。
