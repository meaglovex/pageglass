# 浏览器主菜单调整（build 31）

2026-09-30，针对主菜单缺少层级、图标和快捷键的反馈，保持 AppKit 原生菜单与现有浏览器行为：

- 窗口操作、资料库、缩放、页面操作和设置分组，统一 SF Symbols 图标及右侧快捷键。
- 历史、书签、捕获与交付、更多工具收进子菜单；保留原有动作，增加已有的新窗口、无痕窗口、扩展入口。
- 缩放合并为减小、实时百分比（点击复位）、放大与全屏。捕获中禁用缩放，达到 50% / 300% 边界时禁用相应按钮。
- 书签栏使用勾选状态；没有捕获结果时禁用复制和打开结果文件夹。
- macOS 27 通过公开 preferredImageVisibility API 明确显示菜单图标。菜单定位使用按钮原点，由 AppKit 处理屏幕边缘；不预先用 NSMenu.size 计算偏移。
