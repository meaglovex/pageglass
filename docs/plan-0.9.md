# 0.9：硬件加速状态与验证

用户目标：增加硬件加速功能。

## 已确认的约束

- 0.8 使用系统 WKWebView；已有 build 31 实机报告返回 WebGL `Apple GPU`，并非纯软件绘制。
- 当前公开 WKPreferences / WKWebViewConfiguration 接口不提供全局 GPU 开关。保留系统自动选择，不新增私有 WebKit 标志，不修改系统安全设置。
- 此阶段实现可见、可复测的硬件加速状态；不把状态页冒充新开启 GPU，也不声称所有网页、视频均已走硬件路径。
- 本期采用系统自动模式。手动总开关需要单独评估内核及实现范围，不包含在本次检测功能中。

## 本次范围

1. 设置新增“性能与图形”页面，说明系统自动管理加速。
2. 显式点击检测后，读取 Metal 设备及 H.264 / HEVC / AV1 硬解码能力。
3. 在独立、非持久 WebView 中运行本地 WebGL 绘制读回和 WebGPU 计算读回，报告通过、不可用或失败；不检查用户当前页面。
4. 支持重新检测和复制诊断报告。关闭设置或离开页面时停止未完成的检测并释放临时 WebView；普通浏览不运行探针。
5. 增加解析、失败状态、取消与真实绘制的验证。版本为 0.9.0-alpha.1，保留所有 0.8 未完成验收项。

## 验收条件

- 原生 Metal 设备信息来自当前系统，不写死硬件型号。
- WebGL 必须实际绘制并读回预期像素；仅创建上下文不记为绘制通过。
- WebGPU 必须执行并读回预期值；不存在、超时或设备失败不能当作通过。
- 视频能力查询只说明系统支持，不声称当前视频实际使用了硬解码。
- 缺失和错误结果有明确状态，无虚假开关，无后台轮询，无外部请求。
- 真机确认设置布局、检测、复制及关闭行为，运行相关单元测试与 smoke。

## 不在本次范围

更换浏览器内核、强制软件渲染、全局 GPU 总开关、修改第三方页面的 WebGL 参数、GPU 利用率仪表盘及未测量的功耗/提速承诺。

## 本期实施状态

上述 1–5 项已实现并完成本机验证，详见 [0.9 验收记录](validation-0.9.md)。版本为 0.9.0-alpha.1（32），尚非正式发布；跨系统覆盖及 0.8 遗留验收继续保留。
