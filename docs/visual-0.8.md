# 0.8 原生界面规则

当前实现覆盖浏览器顶部和设置，其他管理界面逐步复用。网页本身继续由 WebKit 布局；主题不会改写网站 CSS。

| 项目 | 规则 |
|---|---|
| 两行顶部 | 标签行 38 pt，导航行 42 pt；书签栏按用户设置显示 |
| 标签 | 宽 110–230 pt；图标 14 pt、标题 12 pt；关闭点击区 28×28 pt，右侧固定 10 pt |
| 新标签 | 紧随实际标签区域，溢出时保持在可见区域；搜索标签在最右侧 |
| 导航 | 图标 15 pt，点击区至少 28×28 pt；左右边距 8 pt，工具间距 6 pt |
| 地址栏 | 32 pt 高，圆角 16 pt；正文 13 pt；输入焦点显示系统焦点色边框 |
| 捕获 | 图标与文字并列，主按钮直接选取；右侧下拉提供整页、交互记录和历史 |
| 工具显隐 | 默认保留下载；主页、设置、记录可选常驻；900 pt 下次要工具收起，进行中状态入口保留 |
| 设置 | 左侧分组 166 pt，内容边距 28 pt；标题 20 pt、正文 13 pt、说明 12 pt；说明使用 labelColor 的 0.78 不透明度 |
| 主题 | 跟随系统、浅色、深色；使用语义色；悬停、按下、选中、禁用及键盘焦点区分 |
| 对比度 | 增强对比度时加重控件边界；正文目标 4.5:1；图标及必要边界目标 3:1，实际检查与 VoiceOver 另记 |
| 动效 | 当前新增控件没有自定义过渡动效，不增加后台动画 |

设置开关与选择立即生效。主页使用独立保存与校验，错误输入保留；其他设置保存不应把未保存的主页误报为已保存。保留期限缩短影响已有捕获时，仍说明范围并确认。

本页为真实实现规格，不代替 UI 验收。布局自动检查、手动截图观察与未完成项目见 [0.8 验收记录](validation-0.8.md)。
